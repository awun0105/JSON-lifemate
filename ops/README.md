# ops/

Những thứ để chạy hệ thống ở nơi khác ngoài máy phát triển.

| Thư mục | Chức năng |
|---|---|
| `docker/` | Ảnh Docker để nộp bài và script chạy thử ảnh. |
| `kaggle/` | Kernel Kaggle tự động: chạy thử trên GPU và vòng chỉnh prompt. |
| `notebooks/` | Notebook chạy và huấn luyện trên Kaggle, Colab. |
| `requirements/` | Danh sách thư viện cho notebook và cho huấn luyện. |
| `scripts/` | Script đóng gói mã, cài đặt máy thuê, sinh file requirements. |
